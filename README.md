# Minha Saúde Feminina 🌸

App Flutter navegável com todas as telas do Figma.

## Como rodar

### 1. Instale o Flutter
- Baixe em: https://flutter.dev/docs/get-started/install/windows
- Extraia em C:\flutter e adicione C:\flutter\bin no PATH

### 2. Instale o Android Studio
- Baixe em: https://developer.android.com/studio
- Instale o Android SDK e crie um emulador (Pixel 6, Android 14)

### 3. Instale o VS Code
- Baixe em: https://code.visualstudio.com
- Instale as extensões Flutter e Dart

### 4. Abra o projeto
``ss`
cd minha_saude
flutter pub get
flutter run
```

## Telas implementadas
- ✅ Splash Screen (com animação)
- ✅ Login (e-mail, senha, Google)
- ✅ Home (categorias + favoritos)
- ✅ Favoritos (lista de artigos)
- ✅ Detalhe do Artigo
- ✅ Lembretes (criar, deletar)
- ✅ Perfil
- ✅ Editar Perfil
- ✅ Categorias (criar nova)
- ✅ Dicas Úteis
- ✅ Suporte
- ✅ Navegação completa com Bottom Nav Bar
